## Plan Mode
Creates a comprehensive project plan for the requested task, outlining EPICs and user stories needed to achieve the objective.

**Prompt in Plan mode**
Prompt in Plan mode: I'm planning to create a shopping website in React and Node.js. The site should allow users to browse products by category, search for items, add products to a cart, and complete checkout. Please help me plan the project by creating issues and breaking it down into epics, features, and tasks.

### Practical Tips

- Use Ask Mode for quick clarifications or brainstorming.
- Leverage Edit Mode for controlled, reviewable code changes.
- Opt for Agent Mode when tackling large-scale or loosely defined tasks.
- Define Custom Modes for specialized workflows to enhance productivity.

These modes are designed to complement your expertise, helping you code faster and more effectively while maintaining control over your workflow
